# BaryLoRA: State-Conditioned Product Barycenters for Federated Low-Rank Adaptation

Anonymous code release accompanying a paper under double-blind review.

This repository will host the source code, configuration files, and evaluation
scripts needed to reproduce the results in the paper:

- the federated LoRA training pipeline,
- the state-conditioned product aggregation and rank-constrained (QR-core)
  return, and
- the scripts that regenerate the reported tables and figures.

The code will be added to this repository during the review period. Please use
the paper's discussion forum for any questions in the meantime.
